# 🍔 App Food em React Native

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)
![Android](https://img.shields.io/badge/Android-3DDC84?style=flat-square&logo=android&logoColor=white)

App de delivery de comida desenvolvido na disciplina de **React Native** da residência em software do **Serratec (2021)**.

As telas foram reproduzidas a partir do [Food App UI Kit (Figma Community)](https://www.figma.com/file/oyOCs9AxQfngImxc12JhYP/Food-App-Ui-Kit-v2-(Community)?node-id=20%3A32).

## Telas

- 🔐 **Login**, **Criar conta** e **Esqueci minha senha**
- 🏠 **Home** com categorias e itens populares
- 🍕 **Detalhe do item** com adicionais (toppings)

## Destaques técnicos

- Navegação em pilha com **React Navigation**
- Persistência local do login com **AsyncStorage**
- Consumo de API com **Axios**
- Gradientes e ícones com **react-native-linear-gradient** e **react-native-vector-icons**

## Como executar

**Pré-requisitos:** Node.js, ambiente React Native CLI configurado (Android Studio + emulador ou celular em modo desenvolvedor).

```bash
npm install
npx react-native run-android
```
